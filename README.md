# sabori_watch

指定したアプリ／サイトを開き続けたら、警告ウィンドウで知らせてくれる Windows 用の常駐スクリプト。
PowerShell 標準機能だけで動き、通信は一切しません（完全オフライン）。

X や YouTube をつい開き続けてしまうときに。「原稿に戻りましょう」

## 仕組み

- 5秒ごとに「今いちばん手前に表示されているウィンドウ」を確認
- 対象に一致したら計測開始。別のウィンドウに切り替わったらリセット（＝連続使用時間の計測）
- 制限時間（初期設定5分）を超えたら、音＋警告ウィンドウを表示
  - モニター中央に、画面の1/4サイズ（縦横それぞれ半分）・最前面で表示
  - 「閉じる」ボタンのほか、ウィンドウの外をクリックしても消える（表示直後0.8秒間は誤作動防止で無効）
- 警告を閉じるとタイマーがリセットされ、また連続使用が続くと再び警告

YouTubeやXはブラウザで開くため、プロセス名ではなく「ウィンドウタイトルの文字列」で判定します（例：タイトルに `YouTube` を含む、Xは `/ X` を含む）。

## ファイル

| ファイル | 内容 |
|---|---|
| `sabori_watch.ps1` | 本体スクリプト |
| `start.bat` | バックグラウンド（ウィンドウ非表示）で起動するランチャー |

## 使い方

### まずテスト実行（コンソール表示あり）

1. `sabori_watch.ps1` を右クリック →「PowerShellで実行」
2. 実行ポリシーで止められた場合は、PowerShellを開いて一度だけ次を実行：
   `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`
3. YouTubeをブラウザで開いて5分放置すると警告が出れば成功。終了はコンソールで `Ctrl+C`

最初は設定の `LimitMinutes` を 1 にして動作確認するのがおすすめです。

### 普段使い（バックグラウンド起動）

- `start.bat` をダブルクリックすると、ウィンドウ非表示で常駐します
- 止めるときはタスクマネージャーから `powershell.exe` を終了
- PC起動時に自動で動かしたい場合は、`Win+R` → `shell:startup` で開くフォルダに `start.bat` のショートカットを入れてください

## 設定の変え方

`sabori_watch.ps1` の先頭「設定」部分の `$Rules` を編集します。

| 項目 | 意味 |
|---|---|
| ProcessNames | 対象プロセス名（`.exe`なし）。ブラウザは `chrome` / `msedge` / `firefox` |
| TitleKeywords | タイトルに含まれていたら対象。アプリ単体で監視するなら空 `@()` |
| LimitMinutes | 連続使用の上限（分） |
| Message | 警告文（デフォルトは「原稿に戻りましょう」） |

ルールは行をコピーすればいくつでも追加できます。例として Discord アプリ単体を10分で警告するルールがコメントで入っています。

## 注意

- 判定は「前面にある時間」だけです。裏で開きっぱなしのタブは数えません
- 警告ウィンドウは最前面に出ます（全画面ゲーム中なども同様）
- Windows の標準機能（PowerShell / Win32 API）だけを使い、通信は一切しません
